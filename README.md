# Trustpilot-dataset-samples

<h2>包含 1001 条 Trustpilot 企业评论的样本数据集</h2>

![Trustpilot 数据集页眉](https://github.com/bright-cn/Trustpilot-dataset-sample/blob/main/Trustpilot-datasets%20(2).png)

一份包含 1000 多条 Trustpilot 软件产品评论记录的数据集样本。该数据集使用 <b>Bright Data API</b> 提取。

<h2>Trustpilot 数据集包含的部分数据点：</h2>

* ```company_name```：公司名称
* ```review_id```：每条评论的唯一标识符
* ```review_date```：评论撰写日期
* ```review_rating```：评论者给出的评分
* ```review_title```：评论标题
* ```review_content```：评论内容
* ```is_verified_review```：True 或 False 值
* ```review_date_of_experience```：评论者接受服务的日期
* ```reviewer_location```：评论者的地理位置
* ```reviews_posted_overall```：评论者撰写的评论数量
* ```review_replies```：公司对该评论的回复
* ```review_useful_count```：该评论获得的其他用户点赞数
* ```reviewer_name```：评论者姓名
* ```company_logo```：指向公司徽标的 URL
* ```url```：直接指向主评论页面的 URL
* ```company_rating_name```：以文字表示的公司评分
* ```company_overall_rating```：以 1 到 5 之间的数字表示的公司评分
* ```is_verified_company```：True 或 False 值
* ```company_total_reviews```：评论总数及其百分比分布
* ```5_star```：五星评论数量及其占评论总数的百分比

以及更多内容。

这是“Trustpilot 企业评论（公开数据）”数据集的样本子集，完整数据集包含超过 <b>2.1 亿条记录</b>。

更新频率：<b>单次、每日、每周、每月、每季度或自定义</b>。

<h2>Trustpilot 数据集有哪些使用场景？</h2>

<h3>1. 监控客户满意度</h3>
利用 Trustpilot 评论评估客户满意度，发现与不同服务或产品相关的重复主题、趋势或问题。此类分析有助于确定需要改进的领域，确保提供更好的客户体验，并支持你通过数据驱动的决策优化产品和服务。

<h3>2. 发现新趋势</h3>
持续跟踪并分析评论数量和情感倾向，衡量新产品、新功能或营销活动对客户认知的影响。这种趋势监控有助于你及时了解客户意见的变化，并相应调整策略，以优化客户互动和满意度。

<h3>3. 竞争基准分析</h3>
利用 Trustpilot 数据比较各竞争对手的客户满意度评分和评论内容。这让你能够识别竞争对手的优势和劣势，获得有价值的洞察，从而改进自身策略并提高客户满意度。
