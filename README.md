# Trustpilot 数据集示例

<h2>1001 条 Trustpilot 商业评论的示例数据集</h2>

![Trustpilot dataset header](https://github.com/bright-cn/Trustpilot-dataset-sample/blob/main/Trustpilot-datasets%20(2).png)

一个包含 1000+ 条记录的 Trustpilot 软件产品评论数据集示例。该数据集使用 <b>Bright Data API</b> 提取。

<h2>Trustpilot 数据集中包含的部分数据点：</h2>

* ```company_name```: 公司名称
* ```review_id```: 每条评论的唯一标识
* ```review_date```: 评论撰写日期
* ```review_rating```: 评论者给出的评分
* ```review_title```: 评论标题
* ```review_content```: 评论内容
* ```is_verified_review```: 是否为已验证评论（True/False）
* ```review_date_of_experience```: 评论者接受服务的日期
* ```reviewer_location```: 评论者的地理位置
* ```reviews_posted_overall```: 该评论者累计发表的评论数量
* ```review_replies```: 公司对该评论的回复
* ```review_useful_count```: 该评论被其他用户标记为“有用”的次数
* ```reviewer_name```: 评论者姓名
* ```company_logo```: 指向公司徽标的 URL
* ```url```: 直达公司主评论页面的 URL
* ```company_rating_name```: 公司评分的文字描述
* ```company_overall_rating```: 公司整体评分（1 到 5 之间的数字）
* ```is_verified_company```: 是否为已验证公司（True/False）
* ```company_total_reviews```: 评论总数及其比例分布
* ```5_star```: 5 星评论的数量及其占总评论的百分比

以及更多数据点。

<h2>Trustpilot 数据集有哪些使用场景？</h2>

<h3>1. 监测客户满意度</h3>
利用 Trustpilot 评论评估客户满意度水平，挖掘不同服务或产品的反复出现的主题、趋势或问题。相关分析有助于识别改进空间，提升客户体验，并以数据驱动的方式优化产品与服务。

<h3>2. 发现新趋势</h3>
随时间跟踪和分析评论量与情感倾向，评估新产品、功能或营销活动对客户认知的影响。此类趋势监测有助于及时洞察客户观点变化，并相应调整策略以优化参与度与满意度。

<h3>3. 竞争基准对比</h3>
利用 Trustpilot 数据对比竞争对手之间的客户满意度与评论内容，识别其优势与不足，为优化自身策略、提升客户满意度提供有价值的参考。
